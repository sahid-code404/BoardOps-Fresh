# UX issues to verify/refine

Phase 01 establishes a preservation-first policy rather than inventing visual changes. During visual baseline capture, explicitly check for clipping, overflow, accidental spacing inconsistency, overlapping responsive elements, broken focus handling, keyboard traps, touch-target failures, loading layout shifts, animation flicker/jank and reduced-motion behavior.

No color, navigation, icon, dashboard-composition, blur, glass or animation-language change is pre-approved. Findings requiring material visual change must be logged in `UI-REFINEMENTS.md` before implementation.
