# ADR-010 — Frontend golden master

Status: Accepted.

`BoardOpsv2rewrite` is the authoritative frontend visual and interaction baseline.

Future engineering work may refactor implementation but must not silently replace BoardOps visual identity. Material visual changes require deliberate product approval.

This ADR covers colors, glass/blur/mesh character, typography hierarchy, icon family, component proportions, navigation model, responsive behavior and animation language.
